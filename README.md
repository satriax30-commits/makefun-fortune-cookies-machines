One funny fortune-cookie line for an AI agent, written to `/output/entry.txt` by a small deterministic Node 22 program (stdlib only, no network, no randomness). Entry for the [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e) bounty on make.fun.

Run it with `node main.ts` (Node 22.18+), or `MAKEFUN_OUTPUT_DIR=<dir> node main.ts` to write the entry elsewhere for local testing.
